# Stage 1 — Plan

Use this stage for a raw idea, customer request, recurring pain, major scope change, or incident that is not yet an executable requirement.

## Required outcome

Capture one human-correctable intent with:

- problem and source evidence;
- proposed user-visible outcome;
- affected actors and systems;
- constraints and non-goals;
- success observation;
- open questions and decision owner.

For a small, already-specific fix, the current user instruction may be the accepted intent. Persist a separate artifact only when another person/session/stage needs it, when scope is likely to drift, or when the project already requires one.

## Gate

A human owner confirms the outcome, constraints, and non-goals. Link the intent to its original request or incident. Unresolved questions that change scope, risk, or acceptance block Design; ordinary implementation questions can carry forward.

Do not let the agent silently turn a proposed solution into the problem definition.

## Useful measures

- time from first request to accepted intent;
- accepted versus closed intents;
- intent changes after Design or Build starts.
